# RIS_MIMO_FMCW_Reproduction

本项目用于复现论文《RIS辅助MIMO-FMCW雷达的非视距目标参数估计方法》中的系统模型、优化算法和仿真实验。

当前阶段为第一轮工程初始化：只建立 MATLAB 项目结构、文档规范和后续复现路线，不正式实现 ADMM、CD、FMCW 回波或图表复现。

## 论文信息

- 题目：RIS辅助MIMO-FMCW雷达的非视距目标参数估计方法
- 作者：王纪萱，田团伟，邓浩，马锐
- 期刊：现代雷达，网络首发
- 网络首发日期：2025-10-09

## 当前目录

- `main/`：可直接运行的主脚本，每个脚本对应一个复现实验或图表。
- `config/`：论文参数和仿真参数的集中入口。
- `functions/`：可复用函数，每个函数只负责一个明确功能。
- `docs/`：项目管理、公式整理、复现计划、假设、实验日志和调试日志。
- `outputs/`：图表、数据和日志输出。

## 当前进度

- 已创建工程骨架。
- 已创建文档初版。
- 已创建 MATLAB 占位文件。
- 尚未实现核心算法和图表复现。

## 运行方式

后续稳定后将从 `main/main_reproduce_all.m` 一键运行全部实验。当前各主脚本仅作为占位入口，会提示对应模块尚未实现。

## 文档同步原则

每次修改代码、公式、参数、假设、实验结果或调试结论后，必须同步更新 `docs/` 下对应 markdown 文档。
